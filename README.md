# Recurrent Networks, Hidden States and Beliefs in Partially Observable Environments

This is a MENG 4th year project, the reinforcement learning environment implementation is based on official implementation from [Lambrechts et al., *Recurrent Networks, Hidden States and Beliefs in Partially Observable Environments*](https://openreview.net/forum?id=dkHfV3wB2l), and extends it to study the robustness and interpretation of belief-like representations.

## Main Contributions

* **Extended POMDP benchmark suite** with T-Maze, Tiger, Starkweather, GridWorld, Mountain Hike and Crying Baby tasks.
* **Multiple belief-alignment measures**, including:

  * linear belief decoding
  * softmax / MLP belief probes using KL, CE and JS divergence
  * Mutual Information Neural Estimation (MINE)
* **Environment-shift experiments** that vary observation quality, transition stochasticity, reward structure and other task parameters to test whether learned representations generalize across related POMDPs.
* **Offline trajectory replay analysis** that replays fixed trajectories through different agent checkpoints, separating changes in the RNN representation from changes in the trajectories generated by the policy.
* End-to-end experimental pipeline for training agents, fitting probes, running environment-shift evaluations and collecting results.

## Structure

```text
agents/              DRQN and recurrent architectures
environments/        POMDP environments and Bayesian belief updates
mine/                 Mutual-information estimator
probe_mi/             MI experiments
probe_regression/     Belief decoding experiments
offline_*             Fixed-trajectory replay / decoupling analysis
pipeline/             End-to-end experiment configurations and runner
```

## Running

Install the main dependencies:

```bash
pip install torch numpy scipy pandas scikit-learn matplotlib wandb
wandb login
```

Train a DRQN agent, for example on Tiger:

```bash
python train.py --name tiger_test tiger --listen-accuracy 0.85
```

Environment available at present:

```bash
tmaze
tiger
starkweather
gridworld
hike
crybaby
```
